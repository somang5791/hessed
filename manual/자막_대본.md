# 청년회 회계 프로그램 매뉴얼 영상 — 자막 대본 (초안)

> 한 칸이 화면 자막 한 장면입니다. 줄바꿈은 실제 자막 줄바꿈과 같습니다.

---

## 1. 지출자 영상

**[시작]**
청년회 회계 프로그램
지출자 사용 방법을 안내합니다.

**[로그인]**
아이디와 비밀번호를 입력하고
로그인 버튼을 누릅니다.

아이디와 비밀번호는
별도로 공유해 드립니다.

**[지출 신청]**
로그인하면
'지출 신청' 화면이 바로 열립니다.

부서와 계정을 고르고
사용 날짜, 금액, 내용을 입력합니다.

결제 방법을 선택합니다.
교회카드로 결제했다면 '교회카드',
개인 돈으로 먼저 냈다면 '전도금'을 고릅니다.

영수증 사진을 첨부하고
'신청' 버튼을 누르면 끝입니다.

**[내 신청 내역]**
'내 신청 내역'에서
신청한 건의 진행 상태를 볼 수 있습니다.

신청 → 승인 → 입금완료 순서로
상태가 바뀝니다.

**[마감 안내]**
전도금은 매달 말일에 마감됩니다.
개인 결제 영수증은
마감 전에 꼭 신청해 주세요.

**[문의]**
사용 중 궁금한 점은
장해라 집사에게 문의해 주세요.

## 2. 회계자 영상

**[시작]**
청년회 회계 프로그램
담당회계 사용 방법을 안내합니다.

**[로그인]**
아이디와 비밀번호를 입력하고
로그인합니다.

아이디와 비밀번호는
별도로 공유해 드립니다.

### ① 할 일 화면

로그인하면
'할 일' 화면이 바로 보입니다.

지금 처리해야 할 일이
순서대로 모여 있습니다.

각 항목을 누르면
해당 작업 화면으로 바로 이동합니다.

→ 지출 승인, 카드 결제 확인,
전도금 입금, 수입 등록 등
다음 할 일에 맞춰 여기서 들어갑니다.

### ② 수입 등록

예산 청구액이나 회비가
계좌에 입금되면

'수입' → '수입 등록'에서
날짜, 항목, 금액을 직접 등록합니다.

### ③ 교회카드 지출

지출자가 교회카드 지출을 신청하면
'할 일'에 표시됩니다.

'카드 결제 확인'으로 들어가
내용을 확인하고 승인하면 끝입니다.

### ④ 일반 전도금

지출자가 전도금을 신청하면
'할 일'에서 바로 들어갑니다.

1. 신청 내용을 확인하고 승인합니다.
2. 지출자 계좌로 입금합니다.
3. '전도금 처리'에서 입금 확인을 누릅니다.
4. '지출 내역'에서 결과를 확인합니다.

**[전도금 마감]**
전도금은 매달 말일에 마감됩니다.
마감 전까지 입금 처리를 마쳐 주세요.

회계 기간이 지나면
그 기간의 지출은 등록할 수 없습니다.

### ⑤ 행사 전도금

행사가 있으면
'행사' → '행사 목록'에서 행사를 만듭니다.

1. 예산에 맞게 전도금을 청구합니다.
2. 받은 전도금을 행사 지출로 등록합니다.
3. 행사 중 쓴 돈을 계속 지출로 등록합니다.
4. 행사가 끝나면 남은 돈을 환입합니다.

환입한 내역은 따로 보이지 않고
전체 금액에만 반영됩니다.

행사 메뉴에서
전체 또는 행사별 정산 내역을
출력할 수 있습니다.

### ⑥ 내역과 현황 확인

'지출' → '현황'에서
예산 대비 사용 현황을 봅니다.

'계좌' → '내역 확인'에서
계좌별 입출금 내역을 봅니다.

### ⑦ 문의

사용 중 궁금한 점은
장해라 집사에게 문의해 주세요.
